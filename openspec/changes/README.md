# Changes

Propuestas de cambio en curso, una carpeta por change:
`<fecha>-<id>/{proposal.md, design.md, tasks.md, specs/<capability>/spec.md}`.

Ver `openspec/AGENTS.md` para la estructura completa y la regla de
conjuntos de archivos disjuntos entre changes abiertos.

Cuando un change se completa y se verifica, su delta se aplica a
`openspec/specs/` y el change se archiva (se mueve a `changes/archivo/` o
se elimina, según se decida — todavía no hay un change archivado que fije
la convención).
